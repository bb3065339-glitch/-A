موقع أبو كريم الحاتي - المرحلة الأولى

الموجود في هذه الحزمة:
- نفس الموقع والمنيو والصور ولوحة الإدارة الحالية محفوظة.
- تحديث الهوية إلى الأحمر والأسود والأبيض.
- حساب زبون اختياري (إنشاء حساب/دخول/خروج).
- الطلب كزائر ما زال متاحًا.
- عند ضبط Firebase، تُحفظ الطلبات داخل حساب المستخدم وتظهر في سجل الطلبات.
- قواعد Firestore تمنع الزبون من قراءة طلبات مستخدم آخر.

التشغيل:
1) أنشئ مشروع Firebase ثم أضف تطبيق Web.
2) فعّل Authentication: Email/Password و Anonymous.
3) أنشئ Firestore Database.
4) انسخ إعدادات Web app إلى firebase-config.js بدل القيم التجريبية.
5) انشر firestore.rules من تبويب Firestore Rules.
6) ارفع index.html و firebase-config.js على نفس المسار في Vercel.

مهم جدًا:
- لن تعمل الحسابات أو الحفظ أونلاين قبل إدخال إعدادات Firebase الحقيقية.
- الطلبات ما زالت تُرسل عبر واتساب كما في الموقع الأصلي؛ الحفظ في Firestore إضافة اختيارية.
- حماية لوحة الإدارة الحالية ما زالت حماية متصفح وليست حماية سيرفر. لا تعتبرها آمنة للنشر العام قبل نقل تسجيل دخول الإدارة إلى API محمي على Vercel وتخزين السر في Environment Variables. هذه الخطوة تحتاج إعداد كلمة مرور الإدارة ومتغيرات السيرفر.
- لا تضع Service Account JSON أو أي مفتاح سري داخل ملفات الواجهة.
