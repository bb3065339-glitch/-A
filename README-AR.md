# موقع أبو كريم الحاتي — نسخة جاهزة للنشر على Vercel

## محتويات المجلد
- `public/index.html` — الموقع الحالي كما تم استلامه.
- `vercel.json` — ترويسات حماية للمتصفح وتقليل مخاطر تضمين الموقع داخل صفحات أخرى.
- `package.json` — أوامر اختيارية لاستخدام Vercel CLI.
- `.gitignore` — يمنع رفع ملفات البيئة والملفات المؤقتة.

## النشر من الهاتف
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. افتح Vercel وسجّل الدخول.
3. اختر **Add New → Project** ثم اربط مستودع GitHub.
4. اترك إعدادات البناء الافتراضية؛ الموقع static ولا يحتاج Build Command.
5. اضغط **Deploy**.
6. عند تعديل الموقع لاحقًا، ارفع النسخة الجديدة من `public/index.html` إلى GitHub، وسيبدأ Vercel نشرًا جديدًا تلقائيًا.

## ملاحظات حماية مهمة جدًا
- `vercel.json` يضيف ترويسات أمان مثل منع تضمين الموقع داخل iframe، ومنع تخمين نوع الملفات، وسياسة مصادر للموارد، وHTTPS.
- لوحة الإدارة الموجودة داخل ملف HTML الحالي تعتمد على تحقق يتم في المتصفح فقط. كلمة المرور المشفّرة وآلية القفل موجودتان داخل كود يصل إلى زائر الموقع؛ لذلك هذه حماية شكلية ضد الاستخدام العادي وليست حماية خادمية حقيقية، ويمكن لمستخدم تقني تجاوزها.
- لا تضع أسرارًا أو مفاتيح API أو كلمات مرور مهمة داخل HTML أو JavaScript.
- الطلبات في النسخة الحالية تُرسل إلى واتساب مباشرة من جهاز العميل؛ لا يوجد API خادمي لحفظ الطلبات أو التحقق منها.
- للحصول على لوحة إدارة محمية فعليًا مع تعديل البيانات من الاستضافة دون إعادة رفع HTML، نحتاج نقل تسجيل الدخول والتحقق وحفظ إعدادات المنيو إلى API خادمي مع تخزين دائم، وإعداد متغيرات بيئة/خدمة تخزين في Vercel. هذا غير مفعّل في هذه الحزمة حتى لا ندّعي وجود حماية غير موجودة أو نضع أسرارًا داخل الواجهة.

## تنبيه توافق
سياسة CSP تسمح بالسكربتات والأنماط المضمنة لأن الموقع الحالي مبني في ملف HTML واحد، وتسمح بالصور من HTTPS وبيانات الصور التي يضيفها محرر الموقع. إذا أضفت لاحقًا خدمة خارجية، قد تحتاج إضافة نطاقها المحدد إلى السياسة بدل فتح كل المصادر.
